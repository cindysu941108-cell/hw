臺中捷運網站原始碼使用說明

資料夾內容：
- index.html：首頁
- hw07css.css：共用 CSS 樣式表
- SecondMetro/history.html：捷運歷史
- SecondMetro/food.html：路線介紹
- SecondMetro/guide.html：車站導覽
- SecondMetro/traffic.html：搭乘資訊

使用方式：
1. 解壓縮整個資料夾，不要更動檔案相對位置。
2. 使用瀏覽器開啟 index.html。
3. 首頁與四個分頁共用根目錄的 hw07css.css。
4. 若要修改版面，請編輯 hw07css.css；若要修改各頁文字，請編輯對應的 HTML。

備註：
此 CSS 是依照目前頁面使用的 class 名稱建立的共用樣式表。
網站為課程作品，非臺中捷運官方網站。
